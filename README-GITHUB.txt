CRUNCHYGO - SIAP DIUPLOAD KE GITHUB PAGES

Isi folder:
- index.html
- about.html
- assets/css/style.css
- assets/js/main.js
- assets/images/

PENTING:
Halaman About Us dan bagian Cerita Kami memanggil gambar:
assets/images/cerita-kami-nayla-fina-berkerudung.png

File gambar tersebut belum termasuk dalam file yang diunggah di chat ini.
Masukkan foto yang dimaksud ke folder assets/images/ dengan nama file persis seperti di atas.
Tanpa foto itu, gambar di bagian Cerita Kami/About Us akan tampak rusak.

CARA MEMPUBLIKASIKAN:
1. Login ke https://github.com
2. Buat repository baru bernama CrunchyGo dan pilih Public.
3. Upload seluruh ISI folder ZIP ini ke repository (bukan file ZIP-nya).
4. Pastikan index.html berada di root repository.
5. Buka Settings > Pages.
6. Pada Build and deployment pilih Deploy from a branch.
7. Pilih branch main dan folder /(root), lalu Save.
8. Tunggu sampai GitHub Pages menampilkan alamat website.

Alamat biasanya berbentuk:
https://USERNAME.github.io/CrunchyGo/

Ganti USERNAME dengan username GitHub milikmu.
